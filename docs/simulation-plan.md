# 新生办事助手仿真测试计划

## 目的与边界

使用完全虚构的“启明大学”通知，验证 PDF 上传、资料检索、适用条件过滤、过期与版本处理、问答引用和清单提取。资料及来源均非真实学校文件；测试结果只能说明这套固定仿真数据上的表现，不能当作真实学校场景准确率。

## 测试资料

`output/pdf/` 包含 7 份可提取文字的 PDF：通用报到、东校区本科、 西校区研究生、东校区住宿、已过期收费、接驳通知旧版及新版。上传信息和顺序以 `sample-data/simulation-manifest.json` 为准。旧版和新版使用同一资料标题，以验证版本替换；过期资料保留启用状态，以验证有效期过滤。

## 执行步骤及验收标准

| 阶段 | 操作 | 通过条件 |
| --- | --- | --- |
| PDF 质量 | 渲染每份 PDF 首页并提取文字 | 中文可读、内容不裁切；每份包含指定关键句和清单标记 |
| 上传 | 使用独立资料库按清单上传 7 份 PDF | 全部上传成功；重复文件被拒绝；新版使旧版停用 |
| 检索 | 固定题集查询报到、住宿、接驳、过期通知 | 有依据题回答并附正确来源；越权/过期/旧版题不引用不适用资料；无依据题拒答 |
| 清单 | 生成东校区本科住宿生与西校区研究生清单 | 仅含适用资料；材料、地点和截止时间按原文显示或标为待核实 |
| DeepSeek | 对有依据及无依据场景各作在线调用 | 有依据回答保留有效引用；无依据不编造 |

测试题和预期写入 `sample-data/simulation-cases.json`，由测试脚本逐项运行并输出原始结果及汇总。报告必须列出失败案例，不将上传成功率或流程测试通过率称为回答准确率。
